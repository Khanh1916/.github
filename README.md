# .github

Default [community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for all repositories owned by **Khanh1916**.

Files here apply to every repository that does not define its own version.

| File | Effect |
|:---|:---|
| `FUNDING.yml` | Shows the **Sponsor** button (links to [GitHub Sponsors](https://github.com/sponsors/Khanh1916)) on repositories with Sponsorships enabled |

To override a default in a specific repository, add that file to the repository itself (e.g. `.github/FUNDING.yml`).
